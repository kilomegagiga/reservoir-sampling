# Reservoir Sampling

Implementation of a weighted sampling method.

## Python3 and PyTest

This project uses python3 with a virtual environment.
This project includes test files to be used with pytest.
Initial setup of virtual environment:
```
$ python3 -m venv env
```
Initial setup of pytest:
```
$ source env/bin/activate
$ pip install pytest
```
Use the following to deactivate the virtual environment:
```
$ deactivate
```
Use the following to subsequently activate the virtual environment:
```
$ source env/bin/activate
```
