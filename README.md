# reservoir-sampling
# Reservoir Sampling

Implementation of a weighted sampling method.

## Python3 and PyTest

This project uses python3 with a virtual environment.
This project includes test files to be used with pytest.
Initial setup of virtual environment:
```
$ python3 -m venv env
```
Initial setup of pytest:
```
$ source env/bin/activate
$ pip install pytest
```
Use the following to deactivate the virtual environment:
```
$ deactivate
```
Use the following to subsequently activate the virtual environment:
```
$ source env/bin/activate
```
## Word Frequencies (based on the British National Corpus)

This project uses word frequency data that is based on the 
British National Corpus.  The frequency lists are a companion to 
Word Frequencies in Written and Spoken English: based on the British National Corpus.  by Geoffrey Leech, Paul Rayson, Andrew Wilson (2001) pp. 320, Longman, London. ISBN 0582-32007-0

The frequency lists are licensed under Creative Commons Attribution-Share Alike 2.0 UK: England & Wales License, available at https://creativecommons.org/licenses/by-sa/2.0/uk/.

The frequency lists are included exactly as provided from the website:  
https://ucrel.lancs.ac.uk/bncfreq/ .
As such, the ShareAlike condition should not apply.  
However, the licensing used for this project is indended to maintain a 
similar licensing ideal, even if not using the same license as the original. 

Regarding the conditions of usage stipulated in the license of frequency lists, the above has been a good faith attempt to give appropriate credit 
for the frequency lists, provide a link to the license of the frequency lists 
and indicate if changes were made to the frequency lists.

Note that all word frequencies are given in units of per million words.
